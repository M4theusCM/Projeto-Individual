## GearUp - Rede Social Automotiva

O projeto GearUp é um projeto individual de CCO da SPTech.

Ele consiste em um site que funciona como uma rede social voltada para o mundo automotivo, desenvolvido como trabalho acadêmico, mas pensado para atender entusiastas, curiosos e apaixonados por carros em geral.

A plataforma permite a interação entre usuários por meio do compartilhamento de conteúdos relacionados à cultura automotiva, promovendo engajamento, troca de experiências e o fortalecimento da comunidade.

## Instalação e Aplicação

1. Clone este repositório:
   ```bash
   git clone https://github.com/M4theusCM/Projeto-Individual.git
   cd Projeto-Individual
2. Instale as dependências:
   ```bash
    npm install

3. Configure o banco de dados (arquivo dbgear.sql disponível em: src>database).

4. Configure o arquivo .env.dev na raiz do projeto com as seguintes informações:
   ```ini
    DB_HOST=localhost
    DB_USER=seu_usuario
    DB_PASSWORD=sua_senha
    DB_DATABASE=nome_do_banco

5. Execute o servidor:
   ```bash
    npm start

6. Abra o projeto no navegador: <a href="http://localhost:3333/">Localhost</a>


## Motivação
O tema do projeto é voltado ao mundo automotivo como um todo, devido ao impacto que essa cultura teve na minha vida. Desde pequeno, sempre joguei jogos relacionados a carros e cresci assistindo a filmes, séries e campeonatos de diferentes categorias automobilísticas. Com isso, decidi criar este projeto com o objetivo de divulgar e valorizar essa cultura.
